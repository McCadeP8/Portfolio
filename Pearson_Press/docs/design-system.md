# Pearson Press Design System

## Selected masthead direction

The primary identity is **The Engraved Standard**, selected from masthead study
V1 as Option A. It uses an uppercase, centered, high-contrast engraved wordmark
with generous clear space, a restrained date line, and strong horizontal rules.

The Engravers MT face used in the prototype is a visual reference only. Before
public distribution, the production wordmark must use a properly licensed face
or custom lettering derived from the selected direction. Customization should
focus on the P terminals, R leg, S curves, spacing between the words, and a
possible PP monogram so the identity is recognizably Pearson Press.

## Principles

- Black, white, and functional grayscale only.
- The masthead is calm and authoritative rather than decorative.
- Headlines must not compete with the wordmark.
- Inside-page running heads use a compact version of the same identity.
- Rules, folios, dates, and section labels form one consistent system.
- White space is an intentional design element.

## Reserved direction

Option B, The Editorial Tower, remains a reference direction only. It is not a
secondary masthead and should not appear in published editions unless the design
system is explicitly revised.
