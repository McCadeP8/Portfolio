# Roadmap

1. Edition Zero: one sport from collection through a manually printed PDF.
2. Edition One: all shared sport components and the six-page daily layout.
3. Nightly Press: scheduling, monitoring, archiving, and automatic printing.
4. Sunday Desk: expanded profiles, weekly analysis, features, and puzzles.
5. Control Panel: Streamlit profile editor, source toggles, preview, and reruns.
6. Hosted Press: authentication, tenant isolation, worker queues, and web delivery.
