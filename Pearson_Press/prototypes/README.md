# Pearson Press Prototypes

- `build_newspaper_prototype.py` generates the six-page US Letter newspaper prototype.
- `build_masthead_styleboard.py` generates the two-page masthead comparison sheet.
- `rendered/` contains reference PDFs generated from these scripts.

The selected brand direction is Option A, **The Engraved Standard**. Prototype
fonts are visual references and must be custom-lettered or appropriately licensed
before public distribution.
